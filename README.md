# VR Room Project

## Description

This is a very basic room with some very basic stuff in it.
I originally wanted to retexture the first room in Doom to just look like a normal room,
but getting it to be accurate enough to be recognizable would have taken too long.
To make the room as accessible as possible, I've thoughtfully included a designated 
non-euclidean infinite falling chamber for those who enjoy VR motion sickness.

I used AI to create the script for the billboarded tree, which works fine on flatscreen but
doesn't actually work perfectly in VR.
